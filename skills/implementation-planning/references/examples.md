# Planning calibration

## Two-increment notification API

List the Accepted storage ADR in Sources and Alignment and cite it in the persistence step. Keep a Proposed delivery ADR out of frozen constraints. Sequence model/service before handler/docs, give each step concrete files and targeted checks, map every AC, and record the additive-schema rollback boundary.

## Anti-pattern signals

Reject plans that hide open design inside steps, say only “update backend” or “run tests,” omit acceptance mapping/rollback, treat plan acceptance as schema/deploy/commit authorization, assign two writers to one shared surface, or let UI/generated/cache/mock state replace an authorized truth owner.
