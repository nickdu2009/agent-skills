# 常见问题
<div class="title-en">FAQ</div>

## 这是客户端插件吗？

不是。仓库发布的是 Agent Skills 标准包，不包含客户端安装器、路径映射或插件清单。

## 应该把 Skill 放到哪里？

开放标准不规定发现路径。请使用目标运行时当前文档给出的目录或导入方式。

## 可以只复制 `SKILL.md` 吗？

只有当该 Skill 没有任何 supporting files 时才可能安全。默认应复制完整 `skills/<name>/` 目录。

## 可以只使用一个 Skill 吗？

可以。每个 Skill 是独立包；从最小集合开始，任务形态出现升级信号时再组合其他 Skill。

## 根目录 `AGENTS.md` 会被一起分发吗？

不会。它只管理本仓库的维护行为。可分发边界只有 `skills/`。

## 为什么没有自动安装命令？

安装路径、冲突规则和权限属于运行时策略，不属于 Agent Skills 包标准。仓库先保持纯标准核心，出现真实兼容问题后再针对性设计适配。

## 旧安装怎么办？

先备份并逐包比较。完全一致且有明确工具管理标记的旧副本可以移走；有本地修改的副本与治理内容应保留并报告。

## 格式通过是否代表运行时可用？

不代表。格式校验只证明包结构和 metadata 合规；发现、触发、权限和 supporting-file 加载仍需真实运行时验证。
